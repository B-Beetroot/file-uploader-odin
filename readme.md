# File Uploader

A full-stack file storage application built with Node.js and Express as part of [The Odin Project](https://www.theodinproject.com/lessons/nodejs-file-uploader).

## Features

- User registration and authentication
- Secure password hashing
- CRUD for folders, files
- File type and size validation
- View and download files
- Cloudinary file storage
- PostgreSQL database with Prisma
- Session-based authentication

## Tech Stack

- Node.js
- Express
- EJS
- Prisma
- PostgreSQL
- Passport.js
- bcrypt
- Multer
- Cloudinary
